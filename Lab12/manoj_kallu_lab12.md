## 2. Problems I Faced and How I Worked on Them

One of the main problems I faced was the large number of DRC violations in the original chip assembly run. The first run had 575 KLayout DRC errors, along with 4657 Magic DRC errors and 378 routing DRC errors.

I tried changing the routing obstruction settings to prevent the router from routing over the core. Blocking all five metal layers caused global routing to fail with a GRT-0116 congestion error. The run reported 421 met1 overflow violations, so I changed the configuration to leave more routing layers available.

Blocking met1 and met2 reduced the KLayout DRC count from 575 to 1. However, the same Metal3 spacing violation remained in the next run. I also tried adjusting the obstruction coordinates, but the DRC count did not change.

For my later run, I blocked met1, met2, and met3 while keeping met4 and met5 available. The flow completed and generated the GDS, but the KLayout DRC count was still 1. This showed me that simply blocking additional routing layers was not enough to fix the remaining violation.

I also checked the Magic DRC results. The count remained at 248 across the runs.

## 4. What I Would Do Differently

One thing I would change is how I approached the routing issues. During the different iterations, I tried blocking different metal layers to reduce routing congestion and DRC errors. Although these changes improved the results significantly compared to my initial run, I was still left with one KLayout DRC error.

I also learned that a change that improves one part of the design can affect another part of the layout. For example, blocking more metal layers can help control routing, but it also reduces the available resources for the router. I would take this into account earlier and make changes based on the detailed reports from each run.

Overall, this project helped me understand that getting a design through the physical-design flow is not just about completing each step. It requires carefully checking the results, understanding the problems, and making decisions based on reports.
